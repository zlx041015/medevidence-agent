# MedEvidence Agent

`MedEvidence Agent` 是一个面向通用常见病症问题的证据驱动型医学信息系统原型。

项目的核心目标不是让模型直接自由回答医学问题，而是通过多阶段工作流，把问题转化为更可追溯、可核验的结果输出流程。

## 核心能力

- 面向通用常见病症问题的医学问答工作流
- 检索、证据抽取、风险核验与总结输出
- 支持离线测试与图形界面展示

## 运行环境

- Python 3.11

安装依赖：

```bash
pip install -e .
```

## 基本运行方式

运行单个问题：

```bash
python -m medevidence_agent.main main "高血压一线管理或治疗的核心是什么？"
```

启动图形界面：

```bash
python -m medevidence_agent.gui
```

## 项目定位

这个项目更适合被定义为：

`一个面向通用常见病症问题的证据驱动型医学 AI 工作流原型`

而不是简单的医学问答脚本。
