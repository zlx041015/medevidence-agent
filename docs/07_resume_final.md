# 简历最终版

## 项目名称

`MedEvidence Agent：面向通用常见病症问题的证据驱动型医学 Agent 与轻量 RAG 工作流系统`

## 简历版描述

- 设计并实现面向通用常见病症问题的证据驱动型医学 Agent 工作流，将问题处理拆解为规划、检索、证据抽取、核验与总结五个阶段。
- 自建 benchmark 数据结构与 100 条示例评测集，搭建 baseline 对比、消融实验、自动评测与结果导出框架。
- 接入 mock / hybrid_mock / PubMed 适配检索链路，支持多病种来源召回、轻量 RAG、来源等级控制与结构化证据回流。
- 设计增强 verifier，从主题一致性、证据支撑、来源等级、冲突检测和时间有效性多个维度提升系统可解释性与安全性。
- 开发图形界面，支持工作流过程展示、结果复制导出、实验结果查看与来源打开。

## 精简版

- 构建面向通用常见病症问题的证据驱动型医学 Agent 原型，集成检索、轻量 RAG、证据抽取、风险核验与结构化回答输出。
- 自建 benchmark 数据结构并实现 baseline 对比、消融实验和实验结果导出。

## 面试定位

你可以把它定义成：

- 面向通用常见病症问题的证据驱动型医学 Agent 系统
- 面向医疗场景的可解释 AI 工作流项目
- 带 benchmark 与消融实验的医学信息系统原型
